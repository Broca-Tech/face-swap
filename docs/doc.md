🧩 全体像

┌─────────────────────┐
│ あなたのブラウザ       │
│ (React + Agora SDK) │
└─────┬───────────────┘
      │ publish (カメラ映像)
      ▼
┌─────────────────────┐
│ AKOOL Live FaceSwap │
│ (Agoraサーバー内で動作)│
└─────┬───────────────┘
      │ subscribe (加工後映像)
      ▼
┌──────────────────┐
│ あなたのブラウザ    │
│ (映像を購読して表示)│
└──────────────────┘

⸻

• ✅ FaceSwap処理そのものはAKOOLサーバー（Agora上）で行われる。
• ✅ こちら側は「カメラ入力」と「加工後出力の購読」を担当。
• ✅ APIはあくまでセッション管理・初期化・状態確認用。
• ✅ AKOOLのセッションがAgoraチャンネルを生成してくれるので、自前でWebRTCを組む必要はない。
• ✅ /update は「セッションに新しい顔画像を送って差し替える」ための制御エンドポイント。

⸻

🔍 注意すべき実装上のポイント1. カメラ映像のpublish
• Agora側では createCameraVideoTrack() → client.publish() でAKOOL側へ送信。
• AKOOLが内部でリアルタイム変換を行い、その結果を同チャンネルにpublish。2. 出力映像の購読
• client.on("user-published") イベントでAKOOLの合成済み映像を受信。
• 加工結果は <video> or <canvas> に描画。3. APIの「detect」結果を送らないとAKOOLが顔位置を認識できない
• opts にランドマーク文字列を渡す必要あり。
